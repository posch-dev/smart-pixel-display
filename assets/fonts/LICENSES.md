# Bundled fonts

Typefaces under `assets/fonts/`. Three carry an explicit licence, the rest are freeware
whose authors are credited here. Every notice below is the one shipped inside the font file
itself, read out of its name table, not copied from a website.

## Minecraft Standard, Polda18

CC0 1.0 Public Domain Dedication. No conditions attached; credited because it is the right
thing to do. Drawn by the dashboard for the clock, the temperatures and the high/low column.

<https://fontstruct.com/fontstructions/show/2247902/minecraft-standard-1>

## Press Start 2P, Cody "CodeMan38" Boisclair

SIL Open Font License 1.1, with Reserved Font Name "Press Start". The licence requires its
text to travel with the font: full text in [PressStart2P-LICENSE.txt](PressStart2P-LICENSE.txt).
One of the four fonts Now Playing can be set to.

<https://zone38.net/font/>

## Selawik, Microsoft Corporation

SIL Open Font License 1.1, with Reserved Font Name "Selawik". Full text in
[Selawik-LICENSE.txt](Selawik-LICENSE.txt). Microsoft's open source replacement for Segoe UI,
used by the web UI wherever Segoe UI is not installed, which in practice means Linux.

<https://github.com/microsoft/Selawik>

## Ikkle 4, Bitty

FontStruct Non-Commercial License, per the font's own metadata. Drawn at four pixels for the
month on the dashboard's calendar icon, and nowhere else.

<https://fontstruct.com/fontstructions/show/1517187/ikkle-1>

## HI Airport Departure, Thorsten Schraut

No licence text in the file, which says only "free download" and points at the author's site.
Drawn at five pixels for the day on the calendar icon, and selectable for Now Playing.

<https://www.hi-score.de>

## PC Senior, High-Logic

Designed by Erwin Denissen in 1999, TrueType conversion © 2001 codeman38. No licence text in
the file. One of the four fonts Now Playing can be set to.

<https://www.high-logic.com/>

## Perfect DOS VGA 437, Fator Caos

No licence text in the file, which names only the author's site. Drawn by the verse panel.

<http://www.fatorcaos.com.br>

## Seven Segment, Onur Cem Tan

No licence text in the file. Drawn by the clock panel, and by the web UI for the clock in the
twin.

<http://www.kraftilab.com>
